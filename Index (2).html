Lab

Three small tools I built to practise checking data

Each opens with example data so you can see it work, then replace it with your own. Everything runs in your browser. Nothing is stored or sent.

Paste a table as CSV. The checker flags blank cells, duplicate rows, repeated IDs with different data, stray spaces, inconsistent spelling, numeric outliers and arithmetic that does not reconcile. The first column is treated as the ID.

Write a case, run it by hand, and type the actual result. The status updates itself: numbers match within half a cent, text matches ignoring case. Leave Actual empty for a case you have not run. The rows below are examples for a simple net pay calculation.
